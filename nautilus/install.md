## Caveats vs the docker backend

- **System packages** are NOT installed automatically (no sudo from a non-root venv).
- **Vulkan ICD** quirk is NOT supported (would require system-level driver configuration). If your repo needs sapien / mani_skill, switch to docker mode.
- **IsaacGym** quirk is NOT supported (requires Python 3.8 + CUDA 11.8 + Ubuntu 20.04 in lockstep). Switch to docker mode.
- **CUDA toolkit** uses whatever the host has (`nvidia-smi`); the venv only pins the Python wheel side (JAX CUDA extras).
- **JAX-first repo**: this project uses JAX/MJX for GPU-accelerated simulation, not PyTorch. The `jax[cuda12]` extra is required for GPU simulation; without it, JAX falls back to CPU only.
