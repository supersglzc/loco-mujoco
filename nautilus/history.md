### Known limitations

- The smoke uses `RLFactory` (random policy, default dense reward), not `ImitationFactory` (which requires HuggingFace dataset + AMASS license).
- `max_episode_steps=1000` was uniformly inferred from `env.info.horizon` for `UnitreeH1`. Other tasks may have different horizons; users who need exact per-task horizons should re-probe each id.
- Task `success_metric` is `null` for all 8 tasks (loco-mujoco's RL reward is dense / unbounded — there is no built-in success classifier).
- `imageio_ffmpeg` emits a `RuntimeWarning: os.fork()` line on every L2 run. Cosmetic — the MP4 is written correctly. Triggered by `imageio_ffmpeg` spawning the ffmpeg child via `subprocess.Popen`; not actionable here.
- **Mjx variants** (e.g. `MjxUnitreeH1`) use a parallel-env JAX API and were intentionally excluded from this spec to keep the smoke entry points deterministic. Add the `Mjx*` ids to `benchmark-spec.json:tasks` later if you want `/rl-experiment` to drive parallel GPU sim — `gpu_sim=true` is already set so the surface is ready.
- **AMASS / SMPL extras** excluded by env-generator (license-gated). If you need motion-capture imitation datasets beyond the default + LAFAN1 set, run `pip install -e '.[smpl]'` after accepting the SMPL license.
